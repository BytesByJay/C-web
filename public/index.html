Cweb

A minimal HTTP/1.0 server written in pure C - under 300 lines, zero external dependencies.

What it does

Single-threaded request handling with basic routing and static file serving. Built with standard POSIX sockets to understand the HTTP protocol and low-level networking from scratch.

Key traits

  • ~250–300 LOC (excluding comments)
  • Only uses socket.h, netinet/in.h, unistd.h etc.
  • No libraries, no frameworks, no build systems required
  • Simple request parsing and route dispatching

Try it

  • About page - demonstrates basic routing
  • Source code on GitHub

Quick start

# Compile (one line, no Makefile needed)
cc -O2 -Wall -Wextra -std=c99 *.c -o cweb

# Run on port 8080
./cweb 8080

Then open http://localhost:8080 or curl it.
