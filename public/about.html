About Cweb

A minimal single-threaded HTTP/1.0 server written in pure C using POSIX sockets.

Origin

Started as a personal project to understand low-level web serving: TCP socket lifecycle, raw HTTP parsing, and response construction without abstractions or libraries.

Project Goals

  • Keep the core implementation under ~300 lines of code (excluding comments)
  • Use only standard C (C99) and POSIX APIs — zero external dependencies
  • Document the code clearly enough to serve as a learning reference
  • Prioritize correctness and simplicity over advanced features

Implementation Details

  • Pure C (C99)
  • POSIX sockets (socket(), bind(), listen(), accept())
  • Manual HTTP/1.0 request parsing (request line + basic headers)
  • Static file serving with correct Content-Type and Content-Length
  • Basic routing via string comparison (easy to extend)
  • Standard library for string handling, file I/O, and memory

What this teaches

Reading and modifying the code will show you:

  • TCP server socket setup and connection handling
  • Parsing HTTP request lines and headers from raw bytes
  • Building valid HTTP/1.0 responses
  • Sending files efficiently with read()/write()
  • Basic error handling and connection lifecycle
  • Manual memory management in a long-running process
