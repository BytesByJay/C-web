📚 About C-Web

A minimalist web server for education

The Story

C-Web started as a learning project from a YouTube tutorial. The goal was to understand how web servers work at the lowest level - using pure C and POSIX sockets.

🎯 Project Goals

  • Educational First: Every line of code is documented to help others learn
  • Stay Minimal: Keep the core under 500 lines of code
  • Zero Dependencies: Only standard C libraries
  • Fast & Efficient: Leverage C's native performance

🛠️ Built With

  • Pure C (C99 standard)
  • POSIX sockets for networking
  • Standard library for file I/O
  • No external dependencies

💡 What You'll Learn

By studying this codebase, you'll understand:

  • How TCP sockets work (socket, bind, listen, accept)
  • HTTP protocol basics (requests, responses, headers)
  • File I/O in C
  • Memory management with malloc/free
  • Structs and function pointers
